# Blue Archive 主题风格拆解与接入方向

更新时间：2026-09-19。

## 1. 研究结论

《碧蓝档案》的主题语言不是“把界面换成蓝色”，而是把**明亮校园日常、未来城市技术感与轻量战术细节**叠加在同一画面中。与当前 P5 主题的黑红、高密度、撕裂冲击不同，Blue Archive 方向需要更大的留白、更薄的线、更高的亮度和更克制的斜切。

本文件来自对日本官方游戏站、动画官方站、16 张视觉资源、4 张代表角色图和 1 段 7.033 秒官网背景视频的实际检查。官方资源目前只作参考，不是运行时候选。

## 2. 证据摘要

- `kv.webp / kv_2.webp`：极亮蓝天、白云、青蓝水面、破损教室边界、蓝白角色与角色光环；高曝光、空气感和通透水光占主导。
- `shares.png`：柔焦校园教室，大面积白与浅青，叠加细密像素/网格、半透明六边形和小型技术标记。
- `game-bks.png`：晴空、城市天际线、角色、单车与枪械并置；光环和青色轨道线让“校园日常 + 未来战术”同时成立。
- 四张学校卡：共享白色徽章、斜切角、极细边线和技术角标，但阿拜多斯/格黑娜/圣三一分别使用青蓝、红紫、黄橙辅助色。
- 角色样本：透明立绘强调完整轮廓、装备和光环；姿态差异适合研究反馈情绪，但文件比例、背景与构图不统一，不宜直接替换现有反馈角色槽。
- 官网背景视频：教室、水岸城市、学院塔和玻璃幕墙依次轮换，靠白色过曝、窗框/树影/道路、仰拍天空和建筑局部进行空间桥接。

## 3. 色彩系统

### 3.1 从官方 CSS 与图片提取的依据

官方 CSS 中出现的明显颜色：

- `#54dcfe`：高亮青色
- `#ffffff`：主表面与文字
- `#000000`：少量高对比文本/遮罩
- `#cccccc`、`#dfdcce`：中性辅助色
- `#9f61cb`：紫色阵营/角色辅助色

图片粗量化：

- `game-bks.png`：`#60c0ff` 约 19.8%，并集中出现 `#40a0ff`、`#40c0ff`、`#a0e0ff`、`#6080a0`、`#404060`。
- `kv.webp`：`#ffffff` 约 12.3%，`#60e0ff` 约 9.3%，`#c0e0ff` 与 `#e0ffff` 各约 8.8%，另有 `#a0e0ff`、`#80e0ff`、`#80ffff`。

### 3.2 主题令牌草案方向

以下只是下一阶段的原创主题令牌方向，尚未写入 `theme.css`：

| 语义 | 建议取值方向 | 用法 |
|---|---|---|
| accent | `#54dcfe` | 焦点、光环、选中边、微发光 |
| accent strong | `#40a0ff` | 主按钮、进度、重要坐标线 |
| background | `#dff7ff` 至 `#80dfff` 的天空渐变 | 全屏空气感背景 |
| paper | 半透明 `#ffffff` | 玻璃卡片与浮层 |
| ink | 深海军蓝，接近 `#17324d` | 正文与可访问性对比；最终需实测 |
| muted | 灰蓝，接近 `#6080a0` | 次要标签与边线 |
| school accents | 青蓝 / 红紫 / 黄橙 | 仅用于阵营或社团分类，不替代系统状态色 |

状态色仍服从项目现有 `SUCCESS / WARNING / LOCKED / PENDING / FAILED / NEW / NOTICE` 语义，不允许用学校阵营色篡改状态含义。所有建议值在实现前必须做对比度复核。

## 4. 栅格与响应式

### 桌面 1440px

- 使用 12 列逻辑栅格；左右安全区建议 64–80px，内容最大宽度约 1280px。
- 主视觉可占 5–7 列，操作面板占 5–7 列；避免 P5 式满屏互相压叠。
- HUD、页码、坐标和小型技术文本沿边缘排布，但不可侵占主任务与表单阅读顺序。
- 角色图若未来获得可用派生资源，应保持完整轮廓并预留光环顶部空间，不能以头部紧贴视口。

### 移动 390px

- 单列，左右安全区 16px；卡片内部 16px，模块间 24px。
- 角色/场景装饰降为背景或局部切片，业务文本与按钮始终在前。
- 现有底部游戏菜单保持四项，不因主题增加一级导航。
- 技术标记、坐标、小号英文标签在窄屏只保留一层，避免装饰文字变成噪声。

### 间距尺度

统一采用 8px 基础尺度：`4 / 8 / 16 / 24 / 32 / 48 / 64 / 80`。4px 只用于细线、图标与文字的微调；主要布局不使用随机间距。

## 5. 字体与字阶

本轮未获取到可确认、可授权复用的官方字体，因此不下载或嵌入疑似原作字体。

- 中文正文：优先系统无衬线，如 `"Microsoft YaHei UI", "Noto Sans SC", sans-serif`。
- 英文/数字技术标签：使用项目可用的中性几何无衬线或等宽系统栈，不伪装成官方字体。
- 显示标题：字重 700–800，允许紧凑字距；避免 P5 式极端手写/撕裂轮廓。
- 技术标签：10–12px，只用于辅助；正文最低字号和行高继续服从可访问性基线。
- 建议桌面字阶：12 / 14 / 16 / 20 / 28 / 40 / 64；移动端显示标题降至 36–48px。

## 6. 轮廓、圆角、阴影与纹理

- 面板：轻斜切或切去单个角，斜切深度建议 8–16px；不要复制 P5 的多重锯齿撕裂。
- 圆角：按钮/输入框 4–8px；大型玻璃卡片 12–16px。阵营卡可用斜切替代圆角。
- 描边：1px 主线，局部 2px 强调；以浅青、白和深蓝构成双层边，不使用厚黑边。
- 阴影：低不透明度蓝灰投影 + 轻微内高光；不使用大面积纯黑硬阴影。
- 纹理：细网格、点阵、半透明六边形、圆环/光环、准星角标、坐标式短线。
- 背景：天空渐变、云层、玻璃反射和抽象校园建筑；正式运行时应原创或授权，不直接复用官方完整场景。

## 7. 组件与交互状态

### 通用卡片

白色或浅青半透明表面，单角斜切，顶部可放短技术编号；hover 时边线与局部光环增强，不整体剧烈旋转或缩放。

### 主按钮

深蓝字/白底或白字/亮蓝底；hover 使用 120–180ms 的亮度与边线变化。active 轻微下压 1–2px。不可只靠颜色表达禁用或状态变化。

### focus-visible

继续使用项目统一双层高对比焦点环。Blue Archive 主题可以把外环改为亮青，但必须在白色、天空蓝和深蓝背景上都清晰可见。

### disabled / locked

降低饱和度但保留文字对比，并显示锁定原因。不能把禁用态做成近乎透明的“消失按钮”。

### loading

采用细圆环、轨道线或六边形扫描；`prefers-reduced-motion: reduce` 下停为静态进度标记，不循环闪烁。

### 空状态

使用原创的校园物件/光环/顾问剪影派生资源与明确文案。官方角色样本只用于研究姿态，未授权前不进入页面。

### hover 与转场

- hover：微发光、边线绘制、短距离 2–4px 位移。
- 页面转场：优先白色过曝 + 天空/玻璃几何 wipe，建议总时长 320–520ms。
- 大场景轮换：官网参考视频约 7 秒包含多个场景；产品界面不应照搬为强制长动画。
- reduced motion：去掉视差、扫线和连续场景轮换，只保留 100–160ms 透明度变化或即时切换。

## 8. 四个一级页面映射

| 页面 | 主题叙事 | 背景/组件方向 | 不改变的业务 |
|---|---|---|---|
| `hub` 据点 | 教室、社团据点、日常集合 | 明亮教室/窗景的原创抽象背景；玻璃任务板；顾问提示 | 据点入口、消息、社团状态 |
| `events` 活动 | 任务板、战术简报、行动日程 | 城市/校园地图线、编号任务卡、细准星和时间轴 | 报名、候补、签到、活动回顾 |
| `community` 同好 | 学校/社团阵营与同伴关系 | 共享结构 + 不同辅助色的社团卡；徽章槽与成员关系线 | 加入/创建小组、社群动态 |
| `me` 我的 | 学生档案、状态界面、个人记录 | 档案玻璃板、编号字段、头像/装备槽的抽象框架 | 个人资料、状态、管理预览边界 |

四项一级导航固定为据点、活动、同好、我的。主题不得新增“角色”“战斗”“抽卡”等原作栏目，也不得伪造游戏账号、战绩、排行或支付能力。

## 9. 与 P5 主题的关键差异

| 当前 P5 | Blue Archive 方向 |
|---|---|
| 黑/白/红，高密度强对比 | 白/青/天空蓝，大留白和空气感 |
| 粗黑轮廓、纸张撕裂、多重斜切 | 1px 细线、玻璃表面、单角轻斜切 |
| 快速红黑 wipe、冲击型角色弹入 | 白色过曝、天空/玻璃几何桥接、轻量弹入 |
| 手写/报纸式标题气质 | 几何无衬线、等宽技术标签、细编号 |
| 装饰常压住内容边缘 | 装饰退到背景和边框，业务信息优先 |
| 角色承担强烈戏剧反馈 | 角色/顾问承担温和提示，战术元素作为反差细节 |

共享业务组件应继续消费语义令牌，不为新主题复制逻辑。实现时应逐步抽取仍然写死的 P5 专属轮廓和动效，而不是整套重写。

## 10. 本轮资源处置与下一步

- `visual`：16 个官方文件，全部为参考，不进入运行时。
- `feedback`：4 个代表角色文件，全部为参考；不统一裁切、不去背景、不压缩为运行时资源。
- `transition`：1 段官网视频，全部为参考；抽帧仅用于分析，临时帧不提交。
- `audio`：不采用。
- `theme.css`：本轮不创建，避免把研究色值误当成已完成主题。
- `theme-registry.js`：本轮不注册 `blue-archive`。

下一阶段应先制作无角色、无 Logo 的原创派生资源包：天空渐变、细网格、六边形、光环、玻璃卡片噪声和 3–4 张抽象页面背景；随后写主题令牌草案、四页进入文案与 1440px/390px 原型，再进行版权复核和 UI 验证。
